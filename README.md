# Derma Divine Aesthetics by DMAC

> A cinematic, scroll-driven web platform engineered for **Derma Divine Medical & Aesthetic Centre** in Lahore, Pakistan. Built with React 18, TypeScript, Tailwind CSS, and Vite.

---

## 🌟 Overview

Derma Divine Aesthetics is an elite clinical sanctuary in Gulberg III, Lahore, bringing together plastic and reconstructive surgery, surgical hair restoration, clinical dermatology, and metabolic wellness.

This digital platform features:
- **Cinematic Canvas Scroller:** 70 synchronized 1080p frame sequence tied to scroll progression with a seamless switch to the 1080p Master Film.
- **Dual Playback Engine:** Zero-flicker progressive streaming with custom cinema HUD (interactive scrubber, timestamp timer, volume/mute toggle, captions overlay, and fullscreen mode).
- **Interactive Before/After Sliders:** Clinical outcome comparisons for facial rejuvenation, hair restoration, and scar revision.
- **Medical Leadership Profiles:** Verified credentials for Dr. Hamza Malik, Dr. Anam Afzal, and clinical specialists.
- **TypeSafe Consultation Triage:** Interactive assessment tool routing patients directly to WhatsApp with pre-filled consultation details.
- **Clinical Integrity Taglines:** Accurate medical credentialing with surgical disclosures.

## 🛠 Tech Stack

- **Framework:** React 18 with TypeScript
- **Styling:** Tailwind CSS with custom emerald & champagne luxury palette
- **Icons:** Lucide React
- **Build Tool:** Vite
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/toseefahmadmalik333/derma-divine-aesthetics.git

# Navigate to project directory
cd derma-divine-aesthetics

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
